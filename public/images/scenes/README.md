# Scene Reference Images

Travel scene assets used by the AI travel photo feature.

Committed layout (generated by `scripts/prepare-scene-images.mjs`):

- `thumbs/256/` — small UI thumbnails
- `thumbs/512/` — hover / larger previews
- `ref/` — capped references sent to the model (≤1536px long edge)

## How to refresh or add images

1. See **[docs/SCENE_IMAGES_SOURCES.md](../../../docs/SCENE_IMAGES_SOURCES.md)** for download sources and filenames.
2. Place full-resolution files at this folder root (e.g. `taipei101.webp`), then run:

   ```bash
   node scripts/prepare-scene-images.mjs
   ```

3. Scene list and status: **[docs/SCENE_IMAGES_STATUS.md](../../../docs/SCENE_IMAGES_STATUS.md)**.

Do **not** commit oversized originals at the scenes root; the prepare script deletes them by default.

## Without these images

The app still works: it uses **text prompts only** when a reference file is missing. Adding references improves output quality and consistency.
